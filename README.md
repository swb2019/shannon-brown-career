## Run

The site is plain HTML, CSS, and JavaScript. It has no package installation or build step.

```bash
python3 -m http.server 8080
```

GitHub Pages deploys from the main branch at the repository root. The canonical URL and previous section anchors remain stable.

## Accessibility and resilience

All content and links work without JavaScript. Reduced-motion preferences are respected; animation can also be paused. The artwork remains static when WebGL is unavailable. Animation stops offscreen and in background tabs. Images and the Manrope font are served locally; the font’s SIL Open Font License is included in assets/Manrope-OFL.txt.

## Content standard

Employment, education, and achievement claims are grounded in Shannon’s résumé and public professional profile. Hourglass Command is presented as a training simulation, with no claim of production deployment or measured customer outcomes. Private repositories are excluded.
